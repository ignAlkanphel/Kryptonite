# Kryptonite

<img src="src/main/resources/icon.png" width="128" alt="Kryptonite icon">

<hr width="100%">

A library for [Palladium](https://git.threetag.net/ThreeTAG/Palladium) that adds a ton of new abilities, conditions, actions, and more!<br>

Notably adapts things from the [Apoli](https://github.com/apace100/apoli/releases) (licensed under MIT) mod for Palladium.<br>
